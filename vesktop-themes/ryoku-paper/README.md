# Ryoku Paper

An original warm dark colour theme for Vesktop/Vencord. It changes Discord's
semantic colour tokens without external fonts, artwork, imports or scripts.
MIT licensed; maintained by Ryostore contributors through the repository issue tracker.

Install from Ryostore, then open **Vesktop → Settings → Vencord → Themes** and
enable **Ryoku Paper**. Choose Discord's dark appearance and disable competing
full themes. Installing does not change enabled themes or QuickCSS.

The preview is a labelled palette illustration, not a screenshot of Discord.
Discord may rename colour tokens in future releases; report compatibility issues
at https://github.com/ryoku-dev/ryostore/issues. Palette bridge integration is
optional and separate; this theme uses fixed colours.
